# Kur Penceresi: GitHub Releases Kaynağı

Tarih: 2026-09-27. Şablon: Teknesyum-UI `ui/templates/kur/`, üretim:

```
node ../Teknesyum-UI/ui/scripts/scaffold.js kur DustyBytes --kaynak releases --depo Teknesyum/DustyBytes --varlik DustyBytes-win-x64.zip --exe DustyBytes.exe --altbaslik "Disk temizleyici" --simge src/DustyBytes.App/Assets/DustyBytes.ico --project .
```

## Ne Değişti

`Kur.bat` artık derlemiyor: GitHub'dan son sürümü sorar, zip ve `.sha256` indirir, özeti denetler, geçiciye açar, `%LOCALAPPDATA%\Programs\DustyBytes` altına taşır, masaüstü ve Başlat kısayolu yazar. Yönetici yetkisi yok; önce yazma izni sınanır. Eski sürüm `.eski` adıyla kenara alınır, yerleştirme bozulursa geri konur.

Pencere Düzen'e göre boyandı: beş adım (✓ / ! / sayı), renk-1 → renk-2 geçişli çubuk ve yüzde, solan mono günlük, Değiştir'li kurulum yeri satırı, Kur → Kuruluyor → Kapat + Programı aç / Yeniden dene. Renkler projenin `theme.tokens.json`'undan üretim anında dolar.

## Bulunan Ve Giderilen

- Pencere kipinde `Get-FileHash` bulunamadı (PS 5.1'de betik işlevi, alt runspace'te yok). .NET `SHA256` ile değiştirildi.
- Uzun hata cümlesi "…" ile kesiliyordu. Hata satırı artık üç satıra sarılır.
